## Comments
**ESSENTIAL!**: 1 tab indent = 2 spaces. Always convert from tabs to spaces for accessibility, especially within Python.  

Always add comments! This repo has tons of code so it'll be impossible to follow without proper documentation.

Each file should (ideally) be prefaced with a short multi-line comment which serves as a description.  
`/*  Description  */`

Header comments divide code into key features.  
`##  Header  ##` or `//  Header  //`
